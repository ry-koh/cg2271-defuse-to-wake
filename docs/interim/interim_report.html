1. Problem statement

Defuse to Wake is a smart lecture alarm. It reads the user's NUSMods timetable and, at wake time, arms a "bomb" that keeps ringing until the user defuses it by clearing sensor-based modules (safe dial, wire cutter, distance tripwire) without tampering.

3. Architecture

Hardware split. The MCXC444 is the game engine and owns all real-time I/O, so the bomb never depends on Wi-Fi. The single-core ESP32-S2 is the renderer and network gateway: OLED, gyro, Wi-Fi and a local web page.

Software (FreeRTOS). MCXC444 task priorities: game FSM 4 > joystick sampler 3 > comm 2 = ultrasonic 2 > feedback (buzzer, LED) 1 > idle. ISRs: UART RX (bytes to a queue), PORT (encoder, buttons) and timer capture (echo), UART above GPIO. Queues join ISRs, FSM and TX; a mutex guards UART TX and game state. Preemption and time slicing are on. ESP32 tasks run by priority, no core pinning: UART link > gyro > display > network = web page.

Inter-board protocol. UART 115200 8N1, frames [0xAA][TYPE][SEQ][LEN][PAYLOAD 0-32][CRC-8], 11 message types, stop-and-wait ACKs, NACK on CRC errors, 100 ms retransmit timeout, 3 retries, 1 s heartbeat.

Cloud data exchange. Everything online is cached, has a fallback and is never used at alarm time. The ESP32 caches the NUSMods timetable in flash and syncs time by NTP. Nightly, the SoCLaaS LLM writes dial and wire brain-teasers: the ESP32 picks each answer, a setter model (x-test-2) writes the puzzle and an independent checker model (x-test-1) must solve it before use. Fallbacks: qwen3.6:35b, "default", then a built-in puzzle bank. After defusing, the AI writes a morning briefing and coach message from the timetable and history. Difficulty is a deterministic rule from recent snoozes and strikes. The last 14 mornings stay in ESP32 flash (source of truth); Firebase Realtime Database is a write-only mirror, queued and retried, never read at runtime. A web page on the same Wi-Fi shows "My mornings" (alarm, lectures, history, settings) and "Engineering" (live bomb, packet log, AI checks, fault buttons) (game-independent).
