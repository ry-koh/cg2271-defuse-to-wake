1. Problem statement

Phone alarms are easy to dismiss and sleep through. Defuse to Wake is a smart lecture alarm: it reads the user's NUSMods timetable and, at wake time, arms a "bomb" that keeps ringing until the user defuses it by clearing sensor-based modules without tampering.

3. Architecture

Hardware split. The MCXC444 is the game engine and owns every real-time input and output, so the bomb loop never depends on Wi-Fi. The ESP32 is the renderer and network gateway: it drives the OLED, reads the gyro and handles Wi-Fi, HTTPS and NTP.

MCXC444 software (FreeRTOS, planned). Tasks, high to low priority: game/alarm FSM with buzzer; joystick sampler; ultrasonic sensor task; comm RX parser; comm TX. ISRs: UART RX (bytes to a queue), PORT (encoder and buttons to a queue or notification) and timer capture (echo), with UART RX above GPIO. Queues connect ISR to parser, input events to the FSM and FSM to TX; a mutex guards UART TX and the shared game state. Preemption and time slicing are enabled. The ESP32 runs network, UART, display and gyro tasks joined by queues.

Inter-board protocol. UART 115200 8N1 carries frames [0xAA][TYPE][SEQ][LEN][PAYLOAD 0-32][CRC-8] with 11 message types. Alarm, config, tamper, command and result messages use stop-and-wait ACKs with a NACK on CRC or length errors, a 100 ms retransmit timeout, 3 retries and a 1 s heartbeat; 3 s of silence marks the link down. The same code is compiled on both boards.

Online services. The ESP32 caches the NUSMods timetable in flash, gets time from NTP and has two saved Wi-Fi hotspots. The SoCLaaS LLM (model x-test-1, then x-test-2, then built-in template clues) writes clues and difficulty as JSON; the ESP32 validates and clamps every field and picks the puzzle answers itself. The reply is cached and requested at start-up or nightly, never at alarm time. Results go to Firebase Realtime Database over REST; failed writes are queued and retried. Everything online is fetched ahead of time and has a fallback, with a built-in offline bomb (dial, wires, tripwire, 180 s).
